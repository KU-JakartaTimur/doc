# Portal Dashboard Alumni

Portal Dashboard Alumni (`Alumni/Dashboard.php`) adalah antarmuka mandiri bagi para peserta didik yang telah dinyatakan lulus dari sekolah Khoiru Ummah.

---

## Fungsi Portal Alumni

1. **Profil Kelulusan Siswa**:
   - Menampilkan identitas resmi alumni: Nama lengkap, Nomor Induk Siswa (NIS), Program Keahlian / Jurusan yang ditempuh, dan Tahun Kelulusan.
2. **Arsip Riwayat Presensi Historis**:
   - Alumni dapat meninjau kembali rekapitulasi kehadiran dan rekam jejak kedisiplinan mereka selama menempuh pendidikan di sekolah.
3. **Pembaruan Data Ikatan Alumni**:
   - Memungkinkan alumni untuk memperbarui informasi kontak telepon, alamat domisili, atau aktivitas terkini (studi lanjut di perguruan tinggi / dunia kerja) demi menjaga jejaring alumni sekolah.
