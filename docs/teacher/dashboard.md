# Dashboard Wali Kelas

Halaman utama bagi Guru / Wali Kelas (`Dashboard.php`). Menampilkan ringkasan kelas yang diampu, statistik kehadiran kelas hari ini, serta grafik tingkat kehadiran selama 7 hari terakhir.

![Dashboard Wali Kelas](/img/screenshots/dashboard-wali-kelas-1.9.10.png)

## Komponen Dashboard

- **Kartu Kelas**: Menampilkan nama/kode kelas yang diampu (contoh: `X BDP A`) beserta tombol **Download QR Code Siswa** untuk mengunduh kumpulan QR siswa di kelas tersebut.
- **Statistik Kehadiran Kelas Hari Ini**: Ringkasan jumlah siswa **Hadir / Sakit / Izin / Alfa / Total** pada hari berjalan.
- **Tingkat Kehadiran Kelas (7 Hari Terakhir)**: Grafik batang yang memvisualisasikan distribusi kehadiran siswa per hari.
- **Tombol Download Laporan**: Mengunduh laporan kehadiran kelas pada periode tertentu.

## Menu Sidebar Wali Kelas

- **Dashboard Wali Kelas**
- **Laporan Kelas**
- **QR Code Siswa**
- **Manajemen Kehadiran**
