# QR Code Siswa Kelas

Menu **QR Code Siswa** (`Teacher/QRCode.php`) memberikan fasilitas mandiri bagi Wali Kelas untuk mengelola, mengunduh, dan mencetak kartu absensi QR Code siswa di rombel kelas asuhannya.

---

## Fitur Utama

1. **Unduh Arsip QR Kelas (Download All)**:
   - Wali kelas dapat mengunduh seluruh file gambar QR Code siswa kelasnya dalam satu berkas arsip ZIP.
2. **Cetak Kartu Massal (Print Grid)**:
   - Membuka halaman cetak berformat kisi (*grid 4 kolom*) siap print langsung di kertas lembar kerja atau kertas tebal.
3. **Cetak Ulang Satuan (Single Print)**:
   - Apabila seorang siswa kehilangan kartu tanda pengenalnya, wali kelas dapat mencetak ulang kartu spesifik siswa tersebut tanpa repot menghubungi staf administrasi pusat.
