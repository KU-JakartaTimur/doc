# QR Code Siswa

Menu **QR Code Siswa** memungkinkan wali kelas mengunduh dan mencetak QR Code seluruh siswa di kelas yang diampu. QR ini digunakan saat proses absensi digital melalui scanner.

![Dashboard Wali Kelas](/img/screenshots/dashboard-wali-kelas-1.9.10.png)

## Fitur

- **Download QR Code Siswa**: Tombol pada kartu kelas di dashboard mengunduh kumpulan QR Code seluruh siswa yang menjadi tanggung jawab wali kelas.
- **Cetak Ulang**: Apabila siswa kehilangan kartu, QR Code dapat dicetak ulang dari halaman ini.
