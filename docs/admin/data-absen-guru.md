# Data Absen Guru

Modul Data Absen Guru (`DataAbsenGuru.php`) menyajikan rekapan presensi guru setiap harinya berdasarkan hasil scan QR Code, serta menyediakan opsi rekap per bulan/tahun.

![Absen Guru Harian](/img/screenshots/absen-guru-1.9.10.png)

## Fitur

- **Daftar Absensi Harian**: Menampilkan kolom No, NUPTK, Nama Guru, Kehadiran (Hadir/Sakit/Izin/Alfa), Jam Masuk, Jam Pulang, dan Keterangan.
- **Tombol REFRESH**: Memperbarui data tanpa reload halaman.
- **Edit Kehadiran**: Admin dapat mengoreksi status kehadiran maupun jam masuk/pulang melalui tombol **EDIT** pada baris guru terkait.
- **Rekap Bulanan/Tahunan**: Tersedia melalui modul Generate Laporan untuk diunduh sebagai PDF/DOC.
