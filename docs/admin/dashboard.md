# Dashboard Admin

Modul Dashboard Admin (`Dashboard.php`) berfungsi sebagai halaman utama untuk pengguna dengan peran Administrator. Di halaman ini, admin dapat melihat ringkasan statistik sekolah, termasuk total siswa, guru, data absensi harian, dan grafik interaktif.

![Dashboard Admin SIKU](/img/screenshots/admin-dashboard-1.9.10.png)

## Komponen Dashboard

- **Kartu Statistik**: Menampilkan ringkasan jumlah siswa, jumlah guru, kelas/jurusan, dan jumlah petugas.
- **Absensi Siswa Hari Ini**: Rekap kehadiran siswa harian berdasarkan filter kelas (Hadir, Sakit, Izin, Alfa, Total).
- **Absensi Guru Hari Ini**: Rekap kehadiran guru harian (Hadir, Sakit, Izin, Alfa, Total).
- **Tingkat Kehadiran Siswa**: Grafik batang statistik kehadiran selama 7 hari terakhir.
- **Tingkat Kehadiran Guru**: Grafik batang statistik kehadiran guru selama 7 hari terakhir.
