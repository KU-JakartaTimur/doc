# Generate Laporan

Modul Generate Laporan (`GenerateLaporan.php`) memungkinkan admin untuk membuat laporan absensi berformat **PDF** maupun **DOC** dari data absensi siswa dan guru.

![Generate Laporan](/img/screenshots/laporan-1.9.10.png)

## Laporan Absen Siswa

- **Pilih Bulan**: Tentukan periode bulan-tahun (contoh: 2026-02).
- **Pilih Kelas**: Dropdown daftar kelas dan jumlah siswa (contoh: X BDP A - 8 siswa).
- **GENERATE PDF / GENERATE DOC**: Mengunduh rekap kehadiran kelas terpilih sesuai bulan yang dipilih.

## Laporan Absen Guru

- **Total Jumlah Guru**: Ditampilkan otomatis (mis. 22 guru).
- **Pilih Bulan**: Periode bulan-tahun yang akan direkap.
- **GENERATE PDF / GENERATE DOC**: Mengunduh laporan kehadiran seluruh guru pada bulan terpilih.
