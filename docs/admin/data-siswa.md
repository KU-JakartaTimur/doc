# Data Siswa

Modul Data Siswa (`DataSiswa.php`) berfungsi untuk mengelola seluruh data siswa.

Fitur yang tersedia:
- Menggunakan Server-side DataTables untuk memuat data dalam jumlah besar dengan cepat.
- Filter berdasarkan Kelas dan Jurusan.
- Fitur pencarian menggunakan AJAX typeahead.
- Registrasi siswa baru beserta pembagian rombongan belajar.
