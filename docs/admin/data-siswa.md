# Data Siswa

Modul Data Siswa (`DataSiswa.php`) berfungsi untuk mengelola seluruh data siswa.

![Daftar Data Siswa](/img/screenshots/data-siswa-1.9.10.png)

## Fitur

- Menggunakan **Server-side DataTables** untuk memuat data dalam jumlah besar dengan cepat.
- **Filter** berdasarkan Tingkat, Jurusan, dan Indeks Kelas.
- Fitur **pencarian** dan **typeahead** menggunakan AJAX.
- **Tambah Data Siswa** dan **Import CSV** untuk registrasi massal.
- Pembagian rombongan belajar (kelas) dapat dilakukan langsung dari halaman ini.

## Tampilan Daftar

Tabel menampilkan kolom No, NIS, Nama Siswa, Jenis Kelamin, Kelas, No HP, dan Aksi (edit, ubah QR, hapus).
