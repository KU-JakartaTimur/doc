# Tata Cara Penggunaan

Panduan ini menjelaskan langkah-langkah dasar untuk masuk dan mulai menggunakan aplikasi **SIKU (Sistem Informasi Sekolah Terpadu)**.

## 1. Halaman Login

Langkah pertama untuk menggunakan aplikasi SIKU adalah melakukan *login* dengan akun yang telah terdaftar.

![Halaman Login SIKU](/img/login.png)

Untuk keperluan ujicoba, masukkan kredensial berikut untuk masuk sebagai Administrator Super:
- **Username / Email:** `adminsuper@gmail.com`
- **Password:** `superadmin`

Klik tombol masuk untuk melanjutkan.

## 2. Dashboard Aplikasi

Setelah berhasil login, Anda akan diarahkan ke halaman **Dashboard Utama**. Di halaman ini, Anda dapat melihat ringkasan data dan mengakses berbagai menu navigasi di bagian *sidebar* kiri.

![Dashboard SIKU](/img/dashboard.png)

### Menjelajahi Modul
- Gunakan **Sidebar** di sebelah kiri untuk berpindah antar modul (seperti Data Siswa, Data Guru, Inventaris, dan Absensi).
- Gunakan menu yang sesuai dengan peran Anda di dalam sistem untuk mengelola data sekolah secara efisien.
